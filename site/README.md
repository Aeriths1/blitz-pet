# Blitz 桌宠 · 发布页

独立的静态页面，不依赖项目里的其他代码。直接双击 `index.html` 用浏览器打开即可预览；要上线时把整个 `site/` 文件夹传到任意静态托管（GitHub Pages、Vercel、Netlify 等）。

```
site/
  index.html     页面本身（样式和脚本都在里面）
  assets/        从项目 assets/ 复制来的 Blitz 手绘 SVG
  media/         放录屏的地方（按下表文件名放入）
```

## 录屏

页面里有 8 个录屏位。把视频按下表文件名放进 `media/`，刷新页面就会自动替换占位框；8 段都放齐后，页面底部的“待录制清单”会自动消失。`.mp4` 和 `.mov` 都认，优先用 `.mp4`。

| 文件名 | 录什么 | 时长 |
|---|---|---|
| `00-hero.mp4` | 主演示（页面最显眼的一段，16:9）。Safari 打开一篇英文技术文章，⌥Q 瞄准一句，短按出钩，钩子咬住拖回，气泡里中文解释逐字出现，最后点“复制” | 15–25 秒 |
| `01-sentence.mp4` | 瞄准状态下慢慢移动鼠标，红色排线一句一句跳，停在中英混排的句子上短按抓取 | 10–15 秒 |
| `02-paragraph.mp4` | 在“预览”打开一页论文 PDF，按住蓄力，进度圈转满，抓回整段并解释 | 10–15 秒 |
| `03-anywhere.mp4` | 连抓三处：暂停的视频字幕、终端里一条报错、编辑器里一行代码注释 | 15–20 秒 |
| `04-pet.mp4` | 鼠标停在他身上（看你、挥手、冒蒸汽），然后拎起来乱晃，甩出去撞墙反弹落地 | 10–15 秒 |
| `05-idle.mp4` | 菜单栏 › 待机动画：冒烟圈、打喷嚏、抓鼠标、造云打雷、戴睡帽打盹，剪成集锦 | 20–30 秒 |
| `06-game.mp4` | 菜单栏 › 玩 Doodle Jump：踩弹簧、吃闪电冲刺、压扁小怪、掉下去结束。裁成竖版 4:5，只留掌机 | 15–25 秒 |
| `07-drift.mp4` | 菜单栏 › 现在就飘：撞中屏幕角落庆祝，再用鼠标碰他落回地面 | 10–20 秒 |

小贴士：

- 用 Blitz 菜单栏的“开始录制”（会同时生成事件日志，方便剪辑时对齐），或 ⌘⇧5 只录一块区域。
- 录之前开勿扰、隐藏桌面图标、换一张干净的浅色壁纸；被抓的文字放大一点（⌘+）。
- 导出 1080p H.264，每段尽量 10 MB 以内。页面里视频静音循环播放，主演示带播放控件。
- `.mov` 转 `.mp4`（装了 ffmpeg 时）：`ffmpeg -i in.mov -vf "scale=1920:-2,fps=30" -c:v libx264 -crf 23 -an media/00-hero.mp4`
