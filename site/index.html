a desk pet that reads for you

看不懂的那句话，
一钩拉回来讲给你听

一只住在 macOS 桌面上的排线手绘 Blitzcrank。按 ⌥Q 指向屏幕上任意一句话，他出钩把这句抓回来，用你本机的 Claude Code 结合上下文，在头顶的思考气泡里用中文解释。

免费安装 看演示

macOS 13+ · Apple Silicon · 需要已登录的 Claude Code · 免费、非商业

“过早优化是万恶之源”：作者在这里引用 Knuth，是想劝读者先把功能写对，再去测哪里真的慢。
three moves

瞄准，出钩，听他说

不用先选中，不用复制，不用切去聊天窗口。鼠标指到哪，他就抓哪。

瞄准

按 ⌥Q 或点一下 Blitz。射道从他的手臂指向鼠标，指到的句子盖上红色排线。

出钩

短按抓这一句；按住约半秒蓄力，进度圈转满就抓整段。按 Esc 或右键收钩。

解释

钩子咬住句子拖回来，解释流进头顶的手绘思考气泡。可以一键复制，也可以随手关掉。

why it feels different

指哪抓哪，而且懂上下文

anywhere

哪里的字都能抓

网页、PDF、编辑器、终端、聊天窗口，连视频画面和图片里的字都行。

context

带着上下文解释

一并参考所在 App、窗口标题和前后文（网页取整页正文），讲的是“这句话在这里是什么意思”。

one / all

短按一句，长按一段

句子按语言规则切分，中英混排也能准确停在句号上。想看整段，按住就行。

your claude

用你自己的 Claude Code

调用本机的 claude -p，不用另填 API key。可在 config.json 里换模型和思考力度，保存即生效。

private

截屏不留底

只在瞄准时拍一张，识字后立即删除。调用时不加载你的 hooks、插件、MCP 和 CLAUDE.md，只发提示词。

sound

有手感

瞄准落到句子上“嗒”一声，出钩呼地一下，咬住时“铛”。钩子带链条、有往返，抓空了也会弹回来。

0.1 s

辅助功能取原文

直接读 App 里的原文和每个字的位置，逐字准确。原生文本、Safari、Chrome、VS Code、Cursor、Obsidian 都行。

0.8 s

Vision 截屏识字

读不到原文时自动改用 Apple Vision：视频里的字、图片、跨行的 PDF 段落。

兜底

剪贴板

两项权限都没开时，抓剪贴板里的文字，挂在钩尖上像一张小纸条。

视频、终端、图片里的字也能抓

App 不开放文字时，他会截一张屏，用 Apple Vision 识别，再把同一窗口里的其他文字当作上下文一起交给模型。

still a desk pet

不抓字的时候，他也闲不住

他站在屏幕底边，眼睛跟着你的鼠标转。整只用排线笔触画成，动起来像纸上的速写活了过来。

摸摸他，拎起他

  • 鼠标停在他身上：看着你、挥手，久一点会转天线冒蒸汽
  • 按住拖动：拎着脑袋乱晃，推进器火苗乱窜
  • 松手：甩出去，撞墙反弹，落地压扁冒一团烟
  • 45 秒没人理：起飞，像老式 DVD 屏保一样满屏飘，撞到角落会庆祝

九段待机小动画

站着发呆时，他会自己找点事做。也可以从菜单栏 › 待机动画 里点名让他演。

打嗝冒烟圈火苗打喷嚏试一拳打盹超速冲刺整点报时抓鼠标画一幅小画造云打雷

晚上 23 点到早上 6 点，他会戴上睡帽，打盹也更勤。

pocket arcade

桌面上开一台手绘掌机

菜单栏选“玩 Doodle Jump”，一台排线画的掌机在右下角打开，他缩小钻进屏幕里，靠推进器往上跳。鼠标左右控制方向，掉下去就结束，Esc 随时退出。

  • 普通台阶、会滑的台阶、一踩就裂的台阶
  • 弹簧把他弹得更高，齿轮可以收集
  • 涂鸦小怪：踩上去压扁，撞上就输
  • 超载闪电：点燃推进器，直冲一段

不想自己玩？选“看他自己跳”，或者放着不管，他闲久了也会自己开一局。

for creators

自带录屏模式

菜单栏点“开始录制”，Blitz 用 macOS 自带的 screencapture 录下主屏，同时把他做的每件事（瞄准、出钩、咬住、气泡、小游戏得分、音效）按毫秒写进旁边的事件日志。

剪视频时可以照着日志自动对齐、放大、配音效。录好的 .mov 和 .jsonl 都在 recordings/ 里，菜单栏一键打开。

get blitz

三分钟装好

需要 macOS 13 Ventura 及以上、Apple Silicon、Node.js 18+、Xcode Command Line Tools，以及已安装并登录的 Claude Code。

# 下载并安装依赖
git clone https://github.com/Aeriths1/blitz-pet.git blitz-pet
cd blitz-pet && npm install

# 编译取词和识字的两个小程序
npm run build:native

# 启动，他出现在屏幕右下角
npm start

开两项权限

系统设置 › 隐私与安全性，给 Electron 打开，然后重启 Blitz。

  • 辅助功能：读指针下文字的原文、位置和前后文
  • 屏幕与系统录音：截屏识字（视频、图片、不开放文字的 App）

想换更快的模型？在 config.json 里把 model 改成 claude-sonnet-5-5 或 claude-haiku-5-5，保存后下一次出钩就生效。

before launch

待录制清单

把录好的视频按下表文件名放进 site/media/，刷新页面就会自动替换占位框；全部到齐后这一节自动隐藏。

文件名录什么时长状态
00-hero.mp4主演示。Safari 打开一篇英文技术文章，⌥Q 瞄准一句（如引用 Knuth 那句），短按出钩，钩子咬住拖回，气泡里中文解释逐字出现，最后点“复制”。15–25 秒待录
01-sentence.mp4瞄准状态下慢慢移动鼠标，红色排线一句一句跳，停在中英混排的句子上短按抓取。10–15 秒待录
02-paragraph.mp4在“预览”打开一页论文 PDF，按住蓄力，进度圈转满，抓回整段并解释。10–15 秒待录
03-anywhere.mp4连抓三处：暂停的视频字幕、终端里一条报错、编辑器里一行代码注释。每处只留“咬住 + 气泡出现”的瞬间。15–20 秒待录
04-pet.mp4鼠标停在他身上（看你、挥手、冒蒸汽），然后拎起来乱晃，用力甩向屏幕一侧，撞墙反弹落地。10–15 秒待录
05-idle.mp4菜单栏 › 待机动画，依次点：打嗝冒烟圈、火苗打喷嚏、抓鼠标、造云打雷；睡帽选“一直戴”再点打盹。剪成每段 3–4 秒的集锦。20–30 秒待录
06-game.mp4菜单栏 › 玩 Doodle Jump。录到踩弹簧、吃闪电冲刺、压扁小怪，最后掉下去结束。裁成竖版只保留掌机。15–25 秒待录
07-drift.mp4菜单栏 › 现在就飘，等他撞中屏幕角落庆祝，再用鼠标碰他落回地面。10–20 秒待录
录制小贴士：用菜单栏的“开始录制”或 ⌘⇧5 都可以；开勿扰模式、隐藏桌面图标、换一张干净的浅色壁纸；把被抓的文字字号调大一点（⌘+），小屏上也看得清；导出 1080p 的 H.264 mp4，每段控制在 10 MB 以内，页面会静音循环播放。.mov 也能直接放，Safari 和 Chrome 都能播。
