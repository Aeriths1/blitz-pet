# Hook sounds

All four are original, layered by this project from sounds that [earshot](https://github.com/Leonxlnx/earshot)
(MIT) synthesises in code; no recordings and no game audio are used.

| File | When it plays | Layers (earshot bank ids) |
|---|---|---|
| hook.ogg | a tap: the hook flies out | fit/snap/switch_flip, whoosh_fast/tight, a chain of hover_tick/detent |
| hook-charged.ogg | a charged hook flies out | pro_impact/air, whoosh_big/jet, glitch/hit, fit/snap/switch_flip, a longer chain |
| hook-charge.ogg | the charge building while the button is held | pro_riser/nblips_hi (0.45 s) |
| hook-full.ogg | the ring fills | pro_notify/ding_2167 |
